# Mi agenda — plan de implementación

Spec: `docs/superpowers/specs/2026-10-06-mi-agenda-design.md`. TDD: cada función pura nace con su test
en rojo. Rama `feat/mi-agenda`. Verificación final: `npx tsc --noEmit && npx vitest run && npm run build`
+ E2E completo + prueba en la demo de producción.

## Tarea 1 — `autoCierre` (lógica pura)

- `lib/types.ts`: `AutoCierre` y `MgmtTask.autoCierre?`.
- `lib/tareasAuto.ts` (+ `.test.ts`): `crearAutoCierre`, `autoCierreCumplido`, `tareasCumplidas`,
  `motivoSistema`, `reabrirTarea`.
- Tests: presupuesto aceptado/completado/presentado/inexistente; pago de antes/después de `desde`, anulado,
  de otro paciente; cita nueva / previa / cancelada / ausente / pasada ya realizada; solo manuales abiertas
  con paciente; `reabrirTarea` saca la última gestión «cerrar» y no toca otras.

## Tarea 2 — la bandeja y los reportes entienden `cumplidas`

- `lib/tareas.ts`: `filasDeTareas(derivadas, guardadas, hoy, cumplidas?)`.
- `lib/tareas-reportes.ts`: `lineasDeTareas(..., cumplidas?)` → «Completada por el sistema».
- `lib/useTareas.ts`: calcula `cumplidas` con citas/presupuestos/pagos; expone `reabrir`.
- `components/tareas/comun.tsx` / `PanelTarea.tsx`: motivo de una personalizada cumplida.
- `app/app/reportes/page.tsx`: pasa `cumplidas`.

## Tarea 3 — `lib/miAgenda.ts`

- `rangoDe`, `esMia`, `itemsDeTareas`, `rutinaDeHoy`, `armarAgenda` (+ `.test.ts`).
- Tests: rango de semana lunes–domingo (también un domingo y un lunes), atrasadas, delegadas, derivadas
  asignadas (solo lectura), rutina con permisos/plan, rutina «con base / sin base», avance, orden estable.

## Tarea 4 — `lib/agendaIA.ts`

- `parsearPropuestas` (JSON con ```json, texto suelto, fechas inválidas o pasadas, tope de 20,
  títulos vacíos/largos), `emparejarPaciente` (acentos, mayúsculas, apellido solo, ambigüedad),
  `resumenSemanaDatos` (sin nombres; montos solo con permiso).

## Tarea 5 — rutas IA

- `app/api/ia/agenda-semana/route.ts`, `app/api/ia/agenda-resumen/route.ts`.
- `ia-gating.exploits.test.ts`: lista de rutas (10) + README (`Las 10 rutas de IA`).

## Tarea 6 — UI

- `NuevaTareaModal`: «Se tacha sola cuando…».
- `components/MiAgenda.tsx`, `AgendaDictado.tsx`, `ResumenSemana.tsx`; `app/app/page.tsx`.

## Tarea 7 — E2E y publicación

- `e2e/mi-agenda.spec.ts` (escritorio y celular; `/api/ia/*` simulado con `page.route`).
- Pasada completa, merge a `main`, push, Vercel Ready, humo en producción, mensaje breve para el grupo.
